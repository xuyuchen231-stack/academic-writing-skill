# 用户默认写作偏好

将这些偏好用于任何领域，当前指令和明确期刊要求优先。不要把既有研究主题写成通用限制。

## 语言

- 清楚、自然、具体、正式；不故作高深，不堆抽象概念，不用华丽词替代论证。
- 讲清为什么做研究、为什么采取方法、为什么评估及结果如何解释，各节有自然过渡。
- 不喜欢破折号插入语、模板式连接词、对立口号和反复“尚未证实”的防御性说明。
- 将必要限定融入句子，例如“一种可能解释是”“这一结果提示”，不取消科学严谨性。
- 解释局限时说明具体条件与影响，不用泛泛免责声明；讨论猜想时顺畅接入可检验的后续研究。
- 中文汇报稿与英文正式稿用途不同；双语对照按段保持内容一致。

## 内容

- 内容完整且有分析，达到正式学术稿件的标准，不只是提纲或摘要集合。
- 综述要比较方法、发展进展、包含与交叉关系、数据和验证证据。
- 扩写补充有效信息；删减保留主线；不擅改研究事实、数字、引用或题名。
- 采用真实文献，经典来源与近期研究兼顾，数量由当前任务决定。
- 保持证据与结论匹配，不保证投稿成功，不将推断冒称已验证结果。

## 排版

- Times New Roman英文字体，适合中文的配套字体；可编辑公式；长文可跳转目录；页码。
- 普通学术版式，不擅自使用紧凑布局降低页数。用户明确要求压缩时遵循，并区分内容删减与排版压缩。
- 默认保留有分析价值的表格；不自动加非表格图。明确要求图时检查文字、边框、连线和乱码。
- 不预设固定文章数、领域或章节。分篇与总框架按实际任务组织。
